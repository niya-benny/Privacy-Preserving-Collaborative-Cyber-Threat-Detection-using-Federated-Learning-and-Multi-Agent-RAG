MITRE ATT&CK T1499.003 Application Exhaustion Flood. Adversaries may target resource intensive features of applications to cause a denial of service (DoS), denying availability to those applications. For example, specific features in web applications may be highly resource intensive. Repeated requests to those features may be able to exhaust system resources and deny access to the application or the server itself.

Tactic: impact. Mitigations listed by MITRE: Filter Network Traffic (M1037).

MITRE ATT&CK T1046 Network Service Discovery. Adversaries may attempt to get a listing of services running on remote hosts and local network infrastructure devices, including those that may be vulnerable to remote software exploitation. Common methods to acquire this information include port, vulnerability, and/or wordlist scans using tools that are brought onto a system.

Tactic: discovery. Mitigations listed by MITRE: Disable or Remove Feature or Program (M1042), Network Intrusion Prevention (M1031), Network Segmentation (M1030).

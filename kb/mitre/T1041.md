MITRE ATT&CK T1041 Exfiltration Over C2 Channel. Adversaries may steal data by exfiltrating it over an existing command and control channel. Stolen data is encoded into the normal communications channel using the same protocol as command and control communications.

Tactic: exfiltration. Mitigations listed by MITRE: Data Loss Prevention (M1057), Network Intrusion Prevention (M1031).

MITRE ATT&CK T1204 User Execution. An adversary may rely upon specific actions by a user in order to gain execution. Users may be subjected to social engineering to get them to execute malicious code by, for example, opening a malicious document file or link. These user actions will typically be observed as follow-on behavior from forms of Phishing.

Tactic: execution. Mitigations listed by MITRE: Behavior Prevention on Endpoint (M1040), Execution Prevention (M1038), Limit Software Installation (M1033), Network Intrusion Prevention (M1031), Restrict Web-Based Content (M1021).

Institution_C incident response playbook for Infiltration. Escalate to the IT service desk (ext 3300). Target recovery time: 2 hours. Automatic blocks are limited to student Wi-Fi ranges; servers need manual approval.

- Isolate the host immediately
- Preserve disk and memory evidence
- Reset credentials used on the host
- Escalate to the incident response lead and scan connected hosts
